GridIron IQ — Quick Start (Beta)

Audience: Beta testers after APK installation Last updated: September 2026 Closed beta: Not in the Play Store yet — download the APK only from gridironiq-beta. Pro access is enabled manually after email to support@gridiron-iq.de. More detail: User Manual · Deutsch

GridIron IQ is a Sleeper companion for multi-league managers: leagues and rosters in one place, scouting notes, trade flags, exposure, and injury overview. Sleeper remains the source for trades and waivers — GridIron IQ helps you decide faster.

1. Install the app

Download the APK

  1. Open the beta page: gridironiq-beta → Download APK (starts downloading app-release.apk).
  2. GitHub alternative: Release page → expand Assets → tap app-release.apk.
  3. Verify SHA-256 against the beta page: D0C39C3364DEF953302F724814ABDC3FB9B43E10D9439B0E23147391C24681E6.

Install the APK (Android sideload)

  1. Open app-release.apk from Downloads (Samsung: My Files → Downloads).
  2. If Android warns “For security, your phone isn’t allowed to install unknown apps from this source” → tap Settings in the dialog → allow installs for My Files / Files / the app you used to open the APK.
  3. Samsung (One UI, e.g. Tab): If install is still blocked → Settings → Security and privacy → Automatic block → turn off → tap the APK again → install.
  4. Confirm installation and open GridIron IQ.

Note: Labels vary by manufacturer/Android version. On stock Android, look for “Install unknown apps” for Chrome or Files. Same flow: allow the source → open the APK again.

  1. Optional: Settings (gear, top right) → set Language to English or Deutsch.

3. Create a cloud account (optional, recommended)

  1. Tap the person icon (top right) → Account.
  2. In Cloud account:

- Enter email and password (min. 6 characters; may require upper/lowercase, digit, special character). - Tap Create account.

  1. Confirm email: Open the link in the confirmation email.

- The app should launch and complete sign-in. - Beta note: If the browser shows “page not reachable” or localhost, the email is often still confirmed — try Sign in in the app. - If needed: Resend confirmation email (on the Account screen).

  1. After sign-in: status shows Signed in — you start on Free.
  1. Enable Pro (beta): Send a short email with your username to support@gridiron-iq.de (subject e.g. “Beta Pro”). We activate Pro manually (usually within 24 hours). Then restart the app or sign out/in — badge shows PRO. Until then, Pro features stay behind the paywall.

Forgot password? On the Account screen → link below the form. Open the reset email on the same device where you requested it.

→ Full detail: User Manual §3

4. Link your Sleeper username

  1. Open Account (person icon, top right).
  2. In Sleeper account:

- Enter your Sleeper username (as in the Sleeper app, e.g. my_username). - Tap Synchronize.

  1. On success: green Linked message with username and user ID.

Errors?

MessageWhat to do
User not foundCheck spelling (no spaces, exactly as in Sleeper)
API errorCheck internet, try again later
  1. After linking, tap Select leagues in Settings — or go there manually.

→ Full detail: User Manual §4

5. Choose leagues for the home screen

  1. Settings (gear) → Leagues on home screen.
  2. Leagues are grouped by season — expand a season (›).
  3. Check all leagues you want to see.

- Season checkbox at the top: toggle all leagues in that season.

  1. Tap Save.
  2. Go to League Overview (logo or menu → League Overview).

Free tier: Maximum 2 active leagues. Enabling more shows a Pro upgrade hint.

No leagues visible?

  • Sleeper not linked → complete step 4 first.
  • No checkboxes set → enable at least one league and save.
  • “No active leagues” on home → tap Go to Settings.

→ Full detail: User Manual §5
