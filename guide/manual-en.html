1. What is GridIron IQ?

GridIron IQ is a fantasy football companion app for Sleeper users — especially managers with multiple leagues (dynasty, redraft, superflex).

What the app does well:

  • All Sleeper leagues and rosters in one place
  • Personal scouting (notes, tags, trade flags across seasons)
  • Cross-league exposure — where do you start the same player?
  • Injury and lineup alerts before gameday
  • Trade board as your decision hub for flags
  • Market values, rankings, and signals (Pro) from our own data pipeline

What the app is not:

  • Not a Sleeper replacement — trades, waivers, and lineup setting stay in Sleeper
  • No automatic buy/sell labels on your roster — you set trade flags

3. Account & cloud sync

Route: Person icon → Account (/account)

Guest vs. signed in

ModeScouting & flagsSync
GuestLocal on deviceNo cloud sync
Signed in (Free/Pro)Local + cloudNotes, tags, flags, Sleeper link, league selection

Without an account the app works fully locally on the Free tier. An account backs up data and syncs across devices.

Create an account

  1. Enter email and password.
  2. Tap Create account.
  3. Open confirmation email → app launches (deep link gridironiq://auth/callback).
  4. If needed: Resend confirmation email.

Known beta issue: Confirmation link sometimes shows localhost in the browser — the address is often still confirmed. Try Sign in in the app.

Sign in & sign out

  • Sign in: Email + password → Sign in.
  • Sign out: Bottom of cloud account section → Sign out. Local guest data stays on device; cloud data returns after signing in again.

Reset password

  1. Forgot password? → request reset email.
  2. Open link in email (ideally on the same device).
  3. Set new password → Save password.

Delete account

Delete account section — irreversible. Export a backup in Settings first. Cancel Google Play subscriptions separately in the Play Store.

4. Link Sleeper

Route: Account → Sleeper account

GridIron IQ reads public Sleeper data (leagues, rosters, player status). You do not enter your Sleeper password in GridIron IQ — only your Sleeper username.

Steps

  1. Enter Sleeper username (exactly as in Sleeper).
  2. Tap Synchronize (first time) or Update username (if already linked).
  3. Success: Linked with username and user ID.

Next

Tap Select leagues in Settings → Settings → check leagues → Save.

Without Sleeper link: Home screen shows a hint that leagues cannot be loaded.

5. League Overview (home)

Route: / — menu League Overview

The home screen is your multi-league dashboard.

Loading & refresh

  • On open: league list first, then rosters in the background (progress: “X/Y leagues — loading rosters…”).
  • Pull-to-refresh: Pull the list down — full data refresh (player catalog incl. injuries, all rosters, projections, waivers).
  • On other screens, pull-to-refresh is not equivalent (partial refresh only). See Pull-to-Refresh & Daten-Aktualität (DE).

Lineup alerts

When relevant, the Lineup alerts card appears at the top:

SectionMeaning
Swap nowOUT, IR, PUP — critical
Likely outDoubtful
Check before kickoffQuestionable
  • Starters only (not bench players).
  • Before kickoff only (live/finished games drop off).
  • Tap league chip → league expands, scrolls to player, brief highlight.
  • Below chips: bench replacement hint (healthy bench player + projection) when available.

Same banner on Portfolio Exposure and Injury analysis.

Search & filters

Search field (“Search league or player…”):

Search matchesResult
League nameLeague visible, full roster (filter chips still apply)
Player nameOnly leagues with that player; per league only matches
EmptyAll active leagues

Filter chips (tags, injured, trade flags): filter at player level. Leagues with no visible matches are hidden.

Auto-expand: Exactly one visible league with an active filter → expands automatically.

League card

Each league shows (when expanded):

  • Roster with position, injury badge, tags, and trade flags
  • Waivers / pending claims with Waivers in Sleeper link
  • Open in Sleeper (league in Sleeper app / browser)

Reorder mode: Reorder leagues (all leagues visible, search/filters disabled).

Open a player

Tap a player → player detail.

7. Notes & Scouting

Central view of all players with notes, tags, or trade flags.

Features

9. Portfolio Exposure

Route: Menu → Portfolio Exposure

Answers: “Where do I have the same player everywhere — especially as a starter?”

Free vs. Pro

FreePro
Player overlaps (list)+ Portfolio cockpit at top
Search, sort+ filters All / Flagged / Injured
Expand → league breakdown+ format tabs 1QB / SF, buy-in weighting

Cockpit (Pro)

  • Summary: leagues, alerts, stake pool (cash leagues)
  • Needs attention: Top players with injury/concentration risk
  • Position bars: QB/RB/WR/TE — tap to filter list
  • NFL team starters: Concentration per NFL team
  • QB stacks: QB + WR/TE from same team

List filters

Default: Overlaps (starter in ≥2 leagues or ≥25% starter share).

Expand player card → per league: starter/bench, buy-in (when enabled).

Metric lines on each card (not on Trade Board):

  • Starts in X/Y leagues — starter share across all active leagues
  • Roster W/Y (%) — how many leagues roster this player

Lineup alerts also appear here (see §5).

System infos (closed beta)

There is no Play Store auto-update. Important messages (new beta APK, changes, maintenance) appear as an overlay after cold start, account switch, language change, or when opening Settings. Tap Read so the message does not auto-show again.

Under Settings → System infos you see a preview of the latest message and All system infos (read-only history). Links in the text are tappable; when a download link is set, use Open link.

Messages match the app language (DE/EN). Admin accounts do not receive system infos (settings show an admin note instead).

  • Before switching devices: export backup.
  • After import: wait briefly — data reloads.
  • Sync issues: sign out/in; pull-to-refresh on home.
